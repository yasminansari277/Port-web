# Ali Shaikh Portfolio

Personal portfolio for Ali Shaikh, a Python backend developer focused on FastAPI,
PostgreSQL, Docker and secure REST APIs.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
bun run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

Build for deployment with `bun run build`, then preview the result with `bun run preview`.
